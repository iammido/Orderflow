# Orderfl0wTalks — Inside the candle

40 seconds, 1080 × 1920, 30 fps. Silent visual draft; narration and music are not recorded.

Install dependencies with your package manager, then run `npm start`. Export with `npm run render`.

Examples are editable in `src/config.ts`. Each scene is individually available in Studio. Timing and ordering live in `src/Reel.tsx`. Colors live in `src/config.ts`.

Buying/selling absorption describes the aggressive side being absorbed. Passive participants are inferred. All values are synthetic teaching examples, not a live feed or trade signal.

Animations are frame-driven for deterministic Remotion playback and export.
